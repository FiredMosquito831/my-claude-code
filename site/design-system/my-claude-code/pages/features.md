# Features override

- The hub is a card grid, not prose. One card per capability area, each linking a
  deep page.
- A deep feature page follows one fixed order: what it is, how it works, what you
  see (figures), configuration (names), limits and behaviour, related links.
- Every deep feature page carries at least three figures. A page that cannot
  reach three is cut or folded into its parent.
- Configuration tables name variables only. A secret-like name never gets a value.
