# Home override

- The hero is the only page with the readout board; everywhere else the readouts
  become a `facts` strip or a table.
- The hero uses a two-column grid (prose 1.25fr, board 1fr) and collapses to one
  column below 960 px, with the board after the calls to action.
- The 12-card capability grid must link every deep page. If a card has no page,
  the card is removed rather than left inert.
- Sections are separated by a 1 px border and generous vertical rhythm; no
  background colour changes between sections.
