# FAQ override

- One `<details>` per question; the answer is present in the HTML and readable
  without JavaScript.
- The visible list is the only source of the FAQPage structured data. The builder
  generates both from the same array, so they cannot drift.
- Each answer is short, direct and sourced. A question that cannot be answered
  from the repository is not asked.
- No marketing superlatives; the tone is the same as the rest of the site.
