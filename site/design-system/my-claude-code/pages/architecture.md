# Architecture override

- Every architecture deep page carries at least two original SVG diagrams.
- A diagram is inline SVG with `role="img"`, a `<title>` and a `<desc>`, a visible
  colour legend, and a text alternative below the figure.
- Diagrams use the same palette as the site and the same mono type. Text is kept
  inside the viewBox; a measured check in the build proves it.
- The security page states principles and controls only. It publishes no
  vulnerability, audit finding or known issue.
