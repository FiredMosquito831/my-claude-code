# Quick start override

- Commands are copy-paste exact and were taken from the repository's own install
  documentation. A command that could not be verified is not shown.
- One code block per platform, labelled with the platform. No tabbed widget: the
  blocks are all visible and the reader picks one.
- Expected outcomes are described in words, never as invented terminal output.
- The "four things that bite" section is kept, because it is the part that stops
  an install from looking broken.
