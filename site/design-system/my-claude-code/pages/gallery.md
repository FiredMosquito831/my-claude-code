# Gallery override

- The gallery holds every approved capture exactly once, grouped by area.
- Thumbnails are 640 px derivatives; the link opens the full 1600 px derivative.
- Every image has a caption and alt text from the manifest. Captions describe the
  state the screen is actually in, including an empty or paused state.
- The index at the top links to each area anchor. The gallery is not paginated and
  no image is behind JavaScript.
