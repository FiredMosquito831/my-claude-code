Environment reference

This page is the LLM gateway environment variables reference. It names the settings, grouped by what they decide, and gives no values. For a secret-like variable it never shows an example: a documentation page is not a place to invent one. The annotated .env.example carries the same names, with comments.

Names, not values. Nothing on this page is a usable setting. Copy a name into your own .env and read its comment in .env.example before choosing a value.

Core server

NameWhat it decides
HOSTthe address the server listens on; loopback by default
PORTthe port the server listens on; 8082 by default
ANTHROPIC_AUTH_TOKENthe bearer token proxy clients present; generated for this machine on first start; required once the host is not loopback
MCC_CONFIG_DIRthe configuration home; environment-only, resolved before the .env is read
MCC_ENV_FILEan explicit dotenv file to load instead of the default one
LOG_LEVELthe server log level
SERVER_LOG_RETAIN_FILEShow many rotated server log files are kept

Request log and analytics

NameWhat it decides
REQUEST_LOG_ENABLEDwhether the persistent request log, and therefore Analytics, is on
REQUEST_LOG_MAX_ROWSthe retention cap; the oldest rows are pruned periodically
LOG_RAW_API_PAYLOADSwhether API payloads are kept raw
LOG_RAW_SSE_EVENTSwhether streamed events are kept raw
LOG_RAW_UPSTREAM_BYTESwhether the provider's own bytes are kept exactly as received; off by default
LOG_API_ERROR_TRACEBACKSwhether API error tracebacks are kept
LOG_RAW_CLI_DIAGNOSTICSwhether CLI diagnostics are kept raw
USAGE_AUTO_REFRESH_SECONDShow often the Usage page refreshes itself while open; zero turns it off
USAGE_LAYOUTwhich of the five Usage layouts is shown

Models, tiers and reasoning

NameWhat it decides
MODELthe model used when nothing more specific matches
MODEL_MYTHOS, MODEL_FABLE, MODEL_OPUS, MODEL_SONNET, MODEL_HAIKUeach coding-agent tier's model
MODEL_VISIONthe model the vision adapter routes an image request to
MODEL_*_FALLBACKSeach route's ordered stand-ins
MODEL_*_PAUSEDthe entries kept in place but never tried
HARNESS_TIER_ALIASESwhether the per-agent tier aliases are offered
VISION_ADAPTER_MODEroute, describe or the behaviour the request would have had without the adapter
REASONING_POLICYthe root reasoning policy
REASONING_MYTHOS, REASONING_FABLE, REASONING_OPUS, REASONING_SONNET, REASONING_HAIKUper-tier reasoning overrides
REASONING_EFFORT_BUDGET_RATIOShow much of the output allowance a thinking rung may take
REASONING_ANSWER_FLOOR_MAXthe answer reserve kept aside from the thinking budget
PROMPT_CACHE_TTL, PROMPT_CACHE_TTL_*the prompt-cache lifetime per route or per tier; client by default

Output budgets, retries and limits

NameWhat it decides
MAX_OUTPUT_TOKENS_CEILINGthe ceiling applied to an output budget; zero is the sentinel for none
MAX_OUTPUT_TOKENS_FLOORthe floor that stops a long prompt squeezing the reply to nothing
MAX_OUTPUT_TOKENS_UNKNOWN_DEFAULTthe value used when no source publishes a model's limit
MAX_OUTPUT_TOKENS_CONTEXT_MARGIN, MAX_OUTPUT_TOKENS_CONTEXT_FLOORthe context-headroom bounds
FALLBACK_TOTAL_TIMEOUT, FALLBACK_FIRST_TOKEN_TIMEOUT, FALLBACK_STALL_TIMEOUTthe deadlines that make a silent model a failure
FALLBACK_RETRY_FIRST, FALLBACK_SKIP_KINDSwhat the chain retries and what it skips
FALLBACK_BENCH_ENABLED, FALLBACK_EJECT_*whether and when a chain entry is benched
PROVIDER_RETRY_ATTEMPTS, PROVIDER_RETRY_BACKOFF_*the retry count and backoff
RATE_LIMIT_COOLDOWN_SECONDS, RATE_LIMIT_COOLDOWN_MAX_SECONDS, RATE_LIMIT_COOLDOWN_MODEwhat a 429 costs a key
RATE_LIMIT_ROUTES_AROUND_MODELwhether a 429 tries another model on the same provider
CREDENTIAL_LOCKOUT_TIERSthe escalating bench for a rejected key
CREDENTIAL_MODEL_BENCH_ESCALATIONhow many models must be limited before the whole key is benched

Web search and fetch

NameWhat it decides
WEB_SEARCH_PROVIDERauto, off, disabled or one search backend
WEB_SEARCH_FALLBACK_POLICYhow far the search chain may move
WEB_SEARCH_CHAIN, WEB_SEARCH_CHAIN_PAUSEDthe ordered search services and the ones paused
ENABLE_WEB_SERVER_TOOLSwhether web search and web fetch are fulfilled at the proxy
WEBSEARCH_PROXYan optional outbound proxy for search
WEBSEARCH_LEGACY_MIN_INTERVAL_SECONDSoptional spacing between keyless-hop requests
WEBSEARCH_LOG_ENABLED, WEBSEARCH_LOG_MAX_ROWSthe web-search log and its retention
DDGS_REGION, DDGS_TIMELIMIT, DDGS_BACKEND, DDGS_SAFESEARCHthe keyless metasearch's region, freshness, engine and safe-search
WEB_FETCH_EXTRACTORthe page extractor; basic restores earlier bytes
WEB_FETCH_ALLOWED_SCHEMES, WEB_FETCH_ALLOW_PRIVATE_NETWORKSthe web-fetch egress rules

Media, messaging and the dashboard

NameWhat it decides
MODEL_IMAGE, MODEL_TTS, MODEL_ASR, MODEL_VIDEOthe four media rails and their chains
MEDIA_UPLOAD_MAX_MBthe optional media upload cap
MEDIA_STORE_ENABLED, MEDIA_STORE_MAX_MBwhether generated media is stored, and its size cap
MCP_MEDIA_APPSthe agents the media server is added to
MESSAGING_PLATFORMdiscord, telegram or none
MESSAGING_RATE_LIMIT, MESSAGING_RATE_WINDOWthe outbound message rate
ADMIN_DESIGN, ADMIN_THEME, ADMIN_MODE, ADMIN_DENSITYthe dashboard's machine-wide appearance
ENABLE_TITLE_GENERATION_SKIP, ENABLE_SUGGESTION_MODE_SKIPthe local optimization rules

Reading a name

  • A blank value means unset; the default applies.
  • A restart-required setting is labelled on the dashboard, because the running process read it at startup.
  • A value is never published here, and a secret-like name never gets an example.
