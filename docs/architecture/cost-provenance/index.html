Where a price came from

A cost is only useful if you can tell how it was produced. MCC prices a request once, as it is logged, and stores the rung of the pricing ladder that answered each field beside the number. A figure no source states is shown as not priced, with the reason.

The ladder

Model metadata is resolved by a single ten-rung ladder, and cost is one of the fields it answers. The provider's own model list is the first rung; models.dev follows; the LiteLLM map is consulted when it is switched on; a cross-provider vote covers what remains; and a field no rung can answer is unpriced. The same resolver answers context, output limit, vision, tool support and the four cache prices, and the Models page and every generated agent catalogue read it, so they cannot disagree about a number or about where it came from.

When the provider's own list states a value, the badge reads provider or models.dev with no rung, because the enrichment step that merged them keeps no record of which won. When the ladder supplied it, the rung is exact, down to a cross-provider vote over strangers who merely share a name, which is badged approximate. Nothing about a request is reconstructed after the fact.

One price, one log row

A request is priced at the moment it is logged, and the rung that answered each price is stored in the row. That is what makes a total traceable: a number on a card can be followed back to the requests that produced it, and each request names its source. The attempt-level export writes one row per model the chain tried, so a fallback that spent tokens is in the export even though it did not answer.

Anthropic's split of cache writes into five-minute and one-hour writes is recorded, and a one-hour write is priced at a rate a source states, or shown as not priced with the reason. Requests that predate the split keep their five-minute price; a historical row is not repriced by a later release.

Reported, estimated, unpriced

Reported and estimated are two figures and are never summed. A reported figure is one a source stated; an estimated figure is one the install computed. Both are shown with their own priced-of-total denominator, so a partial figure cannot read as a complete one. A request no source could price is a dash, not a zero, and a request with no price does not quietly enter a total as if it cost nothing.

The all-time strip below the stat cards is never pruned, so it keeps counting after stored rows roll over at the retention cap. All time in a range control means all time still stored, and the two figures are labelled so they cannot be confused.

Usage is not cost

What a provider says is left is a different figure from what a request cost. The Usage page shows the Claude and ChatGPT subscription windows with their reset times, the credits and rate-limit figures that Nous Portal, DeepSeek, OpenRouter, Kimi and Command Code send on responses you already get, and a Read now button that asks seven providers for their own figure. A window and a cash balance are two blocks and never one total. A provider that publishes a percentage is shown as a percentage, with no currency sign beside it.

A read can never charge a key or bench a provider. The page refreshes on its own only while it is open, at an interval you set, once per provider, and a hidden tab reads nothing. A 429 skips only the provider that sent it, and a repeatedly failing provider backs off on its own.

Media and the marketplace

Media requests are priced like chat ones: a provider figure, then models.dev, then LiteLLM when on, else unpriced. A Mistral image is recorded unpriced because no source publishes a per-image rate for it, and MCC never invents one. InferHub is a marketplace rather than an ordinary provider: a profile sets a price ceiling, and MCC sends that ceiling on every attempt so a request is never charged above it.

Limits and behaviour

  • A price is never invented, rounded up to a plausible number or copied from an old README.
  • A total with no denominator is not published.
  • A request whose cost came from an estimate is marked as estimated, not reported.
  • The all-time figure and the stored-window figure are separate and labelled.
  • A media model that a provider declares no price for stays unpriced.
