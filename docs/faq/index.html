Questions this site is asked most

Each answer below is written from the product's own documentation and, where it matters, from the source. The same questions and answers are published as structured data for search engines, generated from this one list so the two cannot drift. It is the LLM gateway FAQ: the questions this site is asked most, answered once.

What is My Claude Code?
A local multi-provider LLM proxy, model router and control plane for AI coding agents. You point the agents at one address on your machine and manage providers, keys, routing, reasoning, budgets, web search and cost in one place.
Does it send anything to a remote server?
No. It has no telemetry and phones home to nothing. Its only outbound traffic goes to the providers you configure, a search service you enable, or a web page a client asked to fetch. The dashboard and admin APIs are loopback-only.
Which coding agents can use it?
Claude Code, Codex, OpenCode and OpenCode 2, Gemini CLI, Crush, Cline, Goose, Aider, Kimi Code, Qwen Code, Command Code, OpenClaw, Hermes Agent, Droid, Pi and Kilo have launchers. Desktop apps and other clients are configured from the dashboard or pointed at the proxy directly.
Which providers are supported?
Sixty provider cards across cloud APIs, subscription and OAuth sign-ins, gateways, local servers and marketplaces, from Anthropic and OpenAI to OpenRouter, Mistral, Gemini, Vertex, DeepSeek, Ollama, LM Studio and llama.cpp. Local models connect through a base URL rather than a key, and any other OpenAI-compatible endpoint can be added as a custom provider.
Is it free?
MCC itself is free under AGPL-3.0-or-later, or a commercial licence by negotiation. The models behind it may be free, paid, subscription-based or local; that is your choice and your account.
Does it work without an API key?
Yes, for the free path. A fresh install routes the Mythos, Fable, Opus and Sonnet tiers to OpenCode Zen's free model with no key at all. The default model and the Haiku tier still point at NVIDIA NIM, so they need a key or a new model.
Where do my keys live?
In one configuration home on your machine, by default ~/.mcc. The .env holds the settings, and the documents beside it hold custom providers, OAuth stores and credential names. MCC never sends a key anywhere except the provider it belongs to.
What happens when a provider is down?
The fallback chain walks to the next model. A model that errors, rate-limits or refuses moves the request down its chain, and the first attempt that succeeds ends the walk. Every step is recorded in the request log with its reason.
Does it retry the same model forever?
No. A 429 benches the key and model pair for the wait the provider published, and the chain moves on. A timeout, a 5xx, a 410 or a plain 400 is treated as the model's answer, so the chain tries a different model instead of spending the rest of the key pool.
Can I use a Claude subscription?
MCC can route an Anthropic subscription credential, but Anthropic's published terms do not permit routing Free, Pro or Max plan credentials on behalf of third-party users, and the risk is to your account. MCC documents the position in full rather than hiding it; read the Anthropic subscription page before enabling it.
What is a tier?
A coding-agent route such as Fable, Opus, Sonnet, Haiku or Mythos, mapped to a real model and an ordered chain. Tier aliases such as mcc/cyber and mcc/best are protocol names for those routes, not models.
What is a fallback chain?
An ordered list of stand-ins behind a route. If the model a request routes to cannot serve it, the next entry is tried, then the next. A model listed twice is tried twice. A paused entry keeps its place and is never tried.
What does a 429 do to my key?
It benches that key for that one model, for exactly the wait the provider published or a configured cooldown when it published none. The key stays healthy for its other models. The key itself is benched only once several models hold a live bench at once.
Can I use several keys per provider?
Yes. Put them in one comma-separated variable and choose a policy: single, round robin, least used or failover. Each key gets its own upstream client and rate-limit window, and the order in the pool is the order the policy reads.
How is cost calculated?
Each request is priced once, as it is logged. The price comes from a ladder: the provider's own model list first, then models.dev, then LiteLLM when it is switched on, then a cross-provider vote. The source that answered is stored beside the number.
Why are reported and estimated cost separate?
Because they are different claims. A reported figure is one a source stated; an estimated figure is one the install computed. MCC never sums them, and every total carries a priced-of-total denominator so a partial figure cannot read as a complete one.
Does it log my prompts?
The request log stores completed requests locally and is searchable across prompt, reply, reasoning and tool calls. It is on by default and controlled by REQUEST_LOG_ENABLED, with a row cap that prunes the oldest rows. Raw provider bytes and payloads are separate opt-in flags. The log is local SQLite, and a hidden dashboard tab reads nothing.
Can I search my request log?
Yes. The search index stores each distinct piece of text in its own file beside the log, so a search does not unpack every stored request. New requests are indexed as they are written, and older ones when you press Build search index.
How do I connect Claude Code?
Run mcc-claude. For the native model picker, run mcc-claude --discover-models. The dashboard's Configure Claude Code page can also write MCC's proxy settings into Claude Code's own settings file.
How do I connect Codex?
Run mcc-codex. It speaks the OpenAI Responses surface and keeps its own generated catalogue, because the Codex App reads that catalogue at startup and must restart to see a later one.
Can I use a local model?
Yes. LM Studio, llama.cpp and Ollama are provider cards that need a base URL rather than a key, and they sit behind the same address and the same routing as a cloud provider.
Does it support images?
Yes. A vision adapter can divert an image request to a model that can see, and describe mode has a sighted model describe each image for a blind tier. Outbound pictures are resized to a 1568-pixel long edge on the router's own copy.
Does it do web search?
Yes. Claude Code's web_search and web_fetch tools are fulfilled at the proxy instead of by Anthropic, over fifteen search backends or a keyless fallback. No Anthropic search credits are used.
Can I run it from Discord or Telegram?
Yes, optionally. A messaging bridge turns chat messages into managed coding-agent sessions, with voice-note transcription and stop and clear commands. It is off by default and skipped cleanly when it is not configured.
What platforms does it run on?
Windows, macOS and Linux, as a server or as a native desktop app with a tray. The one-liners install a managed Python 3.14 through uv, so no system Python is needed. The desktop app is a window onto the same server.
How do I update it?
The dashboard announces releases and installs them with checksum verification, or re-run the install command, which always fetches the newest release. An update is atomic: the new version is built beside the running one and swapped in only after it answers the health check. The desktop window shows each stage while it runs.
How do I uninstall it?
Run the uninstall one-liner, or mcc uninstall if you installed through npm. It verifies every MCC command is gone before it reports success. The desktop app is removed separately, through the platform's own mechanism.
Is it affiliated with Anthropic, OpenAI or Google?
No. My Claude Code is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by Anthropic, OpenAI, Google or OpenCode. Claude, Codex, ChatGPT and Gemini are trademarks of their owners. Provider names are used to describe what the software connects to, not to claim a relationship.
Where is the full documentation?
The repository's docs/ directory holds the complete usage guide, the routing reference, the architecture file and the per-surface guides. The dashboard's Docs page renders the same documents offline for the version you installed.
Why does the dashboard not open?
The usual reasons are a server that is not running, a different port, or a configuration directory the launcher and the server do not share. Check mcc-server --version, then the health endpoint, then MCC_CONFIG_DIR if you set it.

Still stuck?

The troubleshooting page covers the failures this site can verify, with the symptom, the cause and the fix. For anything else, the repository's issue tracker is the channel, and a security report has its own private route.
