Claude Code through one local address

Claude Code is Anthropic's terminal agent, and it is one client here, not the frame around everything else. mcc-claude points it at My Claude Code on your machine, so the model behind its next request can be any provider you have configured, with a fallback chain and a priced log entry behind it. It is the Claude Code proxy setup in one command.

The command

Install Claude Code yourself, because MCC never installs an agent, then launch it through the proxy with one command:

Launch Claude Code against the local proxy
mcc-claude

The launcher sets the proxy address and the proxy token in the child process only, so nothing is written into your shell profile, your Claude Code settings or your own authentication. Every argument you pass is handed to Claude Code unchanged, which means the launcher is a drop-in replacement for the command you already type.

Add --discover-models to wire Claude Code's native /model picker to MCC's catalogue, which is built from the models your routes actually resolve to:

Launch with the native model picker wired to MCC's catalogue
mcc-claude --discover-models

A single prompt runs the same way, because -p is Claude Code's own flag: mcc-claude -p "summarise this diff". mcc-claude-old keeps the earlier launch shape, which sets the full proxy environment and leaves auto-compact on.

What Claude Code gets

  • One address for every provider. Anthropic Messages traffic reaches whichever model your tiers resolve to, including a local server, without a second client configuration.
  • Fallback chains. When the first model cannot serve a request, the next rung is tried before the agent sees a failure, and each step is recorded.
  • Reasoning control and output budgets, translated once into each provider's own dialect rather than set per client.
  • Credential rotation and health, so a rate-limited key is benched and another key in the pool is tried for the same request.
  • A priced request log: which model answered, which key it used, how many tokens it spent and where the price came from.
  • The web tools, when the proxy's web-search setting is on. Claude Code's web_search and web_fetch are fulfilled at the proxy instead of by Anthropic.

What the launcher does not change

Your Claude Code installation, its settings files and its own authentication are untouched. The launcher sets environment variables for one process and exits with it, so a terminal that never ran mcc-claude is exactly the terminal it was before. If Claude Code is not installed, the launcher prints Anthropic's own install line and exits rather than installing anything on your behalf.
