OpenCode through one local address

OpenCode is an open-source terminal agent that reads its providers from a config file. mcc-opencode points it at My Claude Code on your machine, so the model behind its next request can be any provider you have configured, with a fallback chain and a priced log entry behind it. It is the OpenCode proxy setup in one command.

The command

Install OpenCode yourself, because MCC never installs an agent, then launch it through the proxy with one command:

Launch OpenCode against the local proxy
mcc-opencode

OpenCode reads its provider configuration from files rather than from arguments, so the launcher writes a config document of its own under the MCC configuration home and points the launched process at it through OpenCode's own OPENCODE_CONFIG variable. That variable names an extra config file that is merged into the precedence chain, so your opencode.json is never read, never written and never backed up.

The generated document names two environment variables rather than the token itself, and the launcher sets them in the child process only, so the proxy token is never on disk. A single prompt runs with OpenCode's own subcommand: mcc-opencode run "summarise this diff".

mcc-opencode models mcc lists the models MCC published, with the limits and prices the metadata ladder resolved. mcc-opencode -m mcc/<provider>/<model> starts on one specific MCC-routed model. OpenCode 2, which installs beside v1 under its own binary, has its own launcher: mcc-opencode2.

What OpenCode gets

  • One address for every provider, over the Anthropic Messages surface OpenCode already speaks.
  • Fallback chains. When the first model cannot serve a request, the next rung is tried before the agent sees a failure, and each step is recorded.
  • A generated model list with the limits and prices the metadata ladder resolved, reachable with models mcc.
  • Credential rotation and health, so a rate-limited key is benched and another key in the pool is tried for the same request.
  • A priced request log: which model answered, which key it used, how many tokens it spent and where the price came from.
  • Per-agent attribution. The launcher marks the request as OpenCode's, so the log can name the agent behind it.

What the launcher does not change

Your own opencode.json is untouched, because MCC writes a separate document and points one process at it. Stop launching through MCC and the file you wrote is the file you have. If OpenCode is not installed, the launcher prints its own install line and exits rather than installing anything on your behalf.
