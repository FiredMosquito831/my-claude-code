The project and its history

My Claude Code is an independent open-source project maintained by FiredMosquito831. It is a local routing layer for AI coding agents, and it says what it does without claiming more.

Status

The current release is 8.17.0. The project is active: providers, routing rules and protocol surfaces change release by release, and the documentation is updated beside the code. The repository is public, the test suite is in the repository, and the issue tracker is the place to report a defect. This site documents the behaviour the repository verifies; where a source disagrees with itself, the discrepancy is noted in the site's own record rather than smoothed over.

How it got here

This repository began as a fork of Alishahryar1/free-claude-code and became a standalone project on 2026-09-05. Every commit, branch and tag carried across unchanged: the Git history here is byte-for-byte the history it always had, and every release from v4.x onward is present with its original notes and assets.

GitHub pull requests are database records rather than Git objects, so they could not travel with the code. They are preserved as documents instead: the repository's history/pull-requests/ directory holds all 284 of them with their descriptions, conversations, reviews and commit lists, plus the raw API payloads. Each one names the commit it merged as, and that commit is in this repository's history.

Two consequences are worth knowing. Pull request numbers written into old commit subjects refer to those archived records rather than to anything in this repository. And release publication dates all read 2026-09-05, because the API cannot backdate them; the tag and commit dates are the real ones.

What was inherited

The model-routing infrastructure inherited from the upstream project by Ali Khokhar stays under its original MIT license, and substantial portions of it remain in this project. The repository's licence file carries the full terms, including the MIT notice. The rest of the project is dual-licensed under the AGPL or a commercial licence, which the licence page sets out exactly.

What this site is

A product site, not a documentation reader. It is generated from the repository by a deterministic builder and committed alongside the documentation source, which it never modifies. Every capability page carries a claims list, every number is either computed from the repository or recorded against the command that produced it, and the screenshots are the product's own captures, reviewed and redacted on copies before publication.

The site is deliberately plain in one respect: it loads no external font, no content delivery network, no analytics and no embed. It reads as text with JavaScript disabled. That is a choice about trust, not a limitation of the tooling.

Contact

The project's GitHub profile is the contact channel: github.com/FiredMosquito831. A defect or a feature request goes to the repository's issues. A vulnerability goes to the private security route named in the repository's policy, never to a public issue.
