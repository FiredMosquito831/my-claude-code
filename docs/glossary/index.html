The words this product uses

MCC uses some ordinary words in a specific way. This page defines them once, from the product's own documentation, so a page elsewhere can use them without repeating the definition.

A — C

Adaptive reasoning
A request, spelled ADAPTIVE, that asks the host to think as much as it decides it needs. It is not an effort level and not a budget; each door says it in the host's own words, and a host with no reasoning field is sent nothing.
Bench
A time-bounded refusal to use a credential or a chain entry. A bench is scoped: a 429 benches a key and model pair, while an exhausted balance benches the whole key.
Budget
An exact output allowance, or the reasoning budget a client supplied. MCC keeps the two separate, and never uses an output limit as a reasoning budget.
Carrier
MCC's envelope for a Responses host's opaque encrypted reasoning item, carried through the client's own transcript. A carrier is host-bound: it is replayed only to the provider, endpoint, account and model that minted it.
Chain
An ordered list of stand-ins behind a route. A model listed twice is tried twice, and each listing is judged when it is reached.
Commit boundary
The moment the first protocol chunk is sent and the HTTP status can no longer change. A failure before it is an HTTP error; a failure after it is an in-band event.
Config home
The one directory that holds the .env, the request log and the documents beside them. It is ~/.mcc by default and is pinned by MCC_CONFIG_DIR.
Country refusal
A 403 that refuses the address rather than the credential. It never locks a key out, and the request still tries the next key, then the next model.
Credential pool
The comma-separated keys behind one provider, each with its own upstream client and rate-limit window, read in the order they are listed.

D — F

Dialect
The reasoning fields one host parses: an effort field and its words, an on/off channel, a numeric budget, an OFF spelling or an adaptive channel. A control is emitted only where the model has the knob and the host has the field.
Direct ref
A model named as provider/model, resolved without a tier. It is one of the three forms the router accepts, beside gateway IDs and tier aliases.
Door
One of the four protocol surfaces a client can enter: Anthropic Messages, OpenAI Responses, Chat Completions or Google Gemini. All four meet the same router.
Exit
One named address in a proxy chain. A refused or dropped request can move to another exit on the same model, within the chain's switch limit.
Failover
Moving from the route's primary model to a stand-in after a failure. It happens before the first streamed chunk; after that, the response is committed.
Fallback
One entry in a chain, or the act of walking the chain. A fallback can be paused, which keeps its place and never tries it.

G — I

Gateway model ID
A model identifier decoded by MCC's own gateway-ID codec, rather than a direct provider ref or a tier alias.
Generation
One provider-runtime snapshot with its own provider instances, limiters and quota state. A hot replacement publishes a new generation; old request leases drain against the one they started on.
Harness
The coding agent behind a request, identified from a header or the user-agent fingerprint. It drives per-agent tier maps and the request log's attribution.
Headroom
The context left after a prompt, which bounds how large an output allowance can be. It is applied after the floor, so it can lower a budget but never re-inflate one the context cannot hold.
InferHub
A marketplace provider that resells pooled accounts behind one key. A profile sets a price ceiling, and MCC sends it on every attempt so a request is never charged above it.

J — L

Key health
A key's state, decided only from signals about the credential: an auth rejection, a 429, or an exhausted balance. Timeouts, 5xx and other 4xx leave it untouched.
Keyless hop
The last search hop, which reads DuckDuckGo's HTML page and then its lite page without a key. It is unofficial and may be rate-limited, which is reported as a rate limit rather than as no results.
Learned fact
A negative this install taught the router, shown with its evidence, expiring on a clock and forgettable per row. A reasoning field a host refused is one example.
Lockout
The escalating bench for a key the provider keeps rejecting with an auth error: five minutes, one hour and one day by default, one step per consecutive rejection.

M — O

Media rail
One of the image, speech, transcription and video routes. A media rail walks its chain like a chat route but keeps its own health, and is never offered to a coding agent.
Model kind
What a model is for: chat, image, speech, transcription or video. A picker offers only its own kind, and a model whose kind is stated and is not chat is left out of the chat catalogue.
Model slug
The provider/model string MCC builds from the provider ID and the exact provider model ID. Free-text entry stays available where a provider cannot list its models.
No-thinking variant
A model-listing entry that forces reasoning off. It exists for compatibility, and the router treats the no-thinking name as a distinct route.
Optimization rule
A narrow local rule that answers a common low-value request before a provider is asked. A request it answers records the rule and the tokens no provider received.
OAuth provider
A provider whose credential is a sign-in rather than a pasted string: a Claude subscription, ChatGPT or Kimi For Coding. It sits in the same grid as a key-based provider.
Output allowance
The number of tokens a reply may use, resolved from the model, the route's ceiling and floor, context headroom and, when thinking is requested, the model's own published limit.

P — R

Provenance
The recorded source of a value. A price carries the rung that stated it; a claim on this site carries the path or command that proves it.
Provider card
One provider's entry on the Providers page: its badge, its key count, its rotation policy and its Configure and Refresh models controls.
Proxy token
The bearer token clients present to the proxy. It is generated for the machine on first start, and it is required once the host is not loopback.
Rail
A route rendered as a row on Model Config: a primary model and its ordered fallbacks. A media rail is the same shape for a media endpoint.
Rate-limit window
One key's own quota state. Every key in a pool has its own, so one key saturating or stalling never throttles the others.
Request log
The local SQLite record of every completed request, with its attempts, tokens, cost and latency. Analytics is computed from it; it is not a second accounting system.
Rotation
Choosing which key in a pool serves a request: single, round robin, least used or failover. Rotation is per pool, and each key's order is the order the policy reads.
Rung
One step of a resolution ladder, such as the pricing ladder or the metadata ladder. A value records the rung that answered it, so two surfaces cannot disagree about its source.

S — U

Safety classifier
Claude Code's narrow auto-mode prompt shape. It is a routing policy, not a short-circuit: MCC forces reasoning off so the client receives a parser-readable verdict.
Search chain
An ordered list of search services with repeats, pause and drag. It is walked at the proxy, and its keys follow the same rotation and health rules as a model key.
Server tool
A tool the protocol expects the server to run, such as web search or web fetch. MCC fulfils it at the proxy instead of sending it upstream.
Subscription window
A plan's usage limit with its reset time, as a provider reports it. A window and a cash balance are two blocks and never one total.
Tier
A coding-agent route such as Fable, Opus, Sonnet or Haiku, mapped to a real model and a chain. A tier alias is the protocol name for one of those routes.
Tier alias
One of mcc/cyber, mcc/best, mcc/good, mcc/medium, mcc/cheap or mcc/vision. It is a pointer to a global route, not a model.
Token optimizer
The page and the opt-in RTK integration that show what never reached a provider: tokens saved, rule counts and prompt-cache effectiveness.
Tuning
A parameter set for the shared rotation engine. The provider tuning excludes the generic cooldown ladder; the web-search tuning keeps it, because a search key that keeps erroring is worth resting.

V — Z

Vision adapter
The route that diverts an image request to a model that can see. In describe mode, a sighted model describes each image and the description is cached on the image's content address.
Wire capture
The recorded message and tool structure actually sent, bounded and inspectable. It is what lets a reasoning adaptation appear in the request detail.
