## What changed

Adopts **ADR 0001** (`docs/adr/0001-desktop-server-deployment-model.md`) — an explicit three-way server-ownership mode so the desktop tray and the headless `mcc-server` coexist without stepping on each other.

- **`server_mode`** (`spawn` / `attach` / `off`) replaces the boolean `server_auto_start`, with a backward-compatible migration.
- **`spawn`** = tray owns a child server (current behavior); **`attach`** = connect to an existing server, never spawn; **`off`** = tray only.
- **Per-platform autostart**, user-configurable: Windows HKCU Run key for `mcc-desktop`, macOS LaunchAgent for `mcc-desktop`, WSL/Linux `systemd --user` (or `.desktop` fallback) for the headless `mcc-server`. Detected via the existing `claude_discovery.native_origin()`.
- **Dashboard "Deployment" section** (server_mode selector + detected-platform autostart) + `mcc-desktop --server-mode` / `--autostart` flags + tray "Server mode" submenu.
- **`mcc-server` is untouched.**
