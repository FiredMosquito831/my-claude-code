## Summary

Command Code's Provider API exposes one live model catalog across two incompatible inference routes. Claude models require native Anthropic Messages; OpenAI and open-source models require Chat Completions. This PR adds one first-class `commandcode/...` provider that routes each family correctly instead of falsely advertising the whole catalog through one transport.

## What changed

- Added `COMMANDCODE_API_KEY`, proxy, multi-key pool/rotation, health/status, model discovery and admin-card integration.
- Added a neutral native Anthropic Messages upstream family with request preservation, validated SSE pass-through, pre-commit retry/holdback, canonical failures and cleanup.
- Added a hybrid Command Code adapter: `claude-*` uses `/provider/v1/messages`; all other live-catalog IDs use `/provider/v1/chat/completions`.
- Preserved catalog `context_length` metadata without inventing unsupported capability flags.
- Added v4.54.0 docs, env, smoke and exhaustive provider contracts.
