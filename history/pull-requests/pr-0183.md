## The gap

`tests/api/test_docs_bundle_wheel.py` builds a real wheel behind `MCC_WHEEL_TESTS=1` — gated deliberately after the nested-`uv` hang (5.49-era) — but nothing ever sets that flag: grep across `.github/`, `scripts/`, `Makefile` finds zero setters, and `git log -S MCC_WHEEL_TESTS` confirms it was never wired. The end-to-end half of the docs-bundle guarantee was decorative: every source-checkout check could stay green while the shipped wheel's Docs bundle broke.

## The fix

New `wheel-e2e.yml`: **manual dispatch + weekly schedule (Wed 02:41 UTC)** — deliberately never on `push`/`pull_request`, so it cannot gate merges. Runs the real wheel build + bundle assertions on `windows-latest` under `MCC_WHEEL_TESTS=1`. Least privilege (`contents: read`), concurrency-grouped, 30-minute timeout sized against the fixture's own 900s build cap. Action SHAs copied from `tests.yml`.

Beyond the brief: a new contract test (`tests/contracts/test_wheel_e2e_workflow.py`, 140 lines) enforces the properties that keep this honest over time — flag set nowhere except this workflow, action pins identical to tests.yml, no push/pull_request triggers, YAML parses.

Also documents the flag and schedule in `docs/RELEASE-CHECKLIST.md`.
