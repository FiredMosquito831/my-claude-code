## What changed

**The report**: analytics export "exports nothing or just a few sloppy rows".

**Root cause (two real bugs, shipped since 5.2.0):**
1. **CSV and XLSX detail exports produced empty data cells.** The renderers were called with the human-readable column labels (`Provider`, `Resolved model`) and used those same labels to look up each data cell — but rows are keyed by SQL column names (`provider`, `resolved_model`). Every `row.get("Provider")` returned `None`, so CSV/XLSX exports were a header with nothing beneath. JSON and TXT were unaffected (JSON uses column names; TXT reads by column name). The aggregate (grouped) exports were also unaffected.
2. **TXT truncated long values** to the header width (`nvidia/nemotron-3-ultra-550b-a55b` → `nvidia/nemotro`). Columns now widen to the longest value and never truncate.

**New capability (your request):**
- **Provider/Model filter** in the export modal — comma-separated, datalist-backed (suggestions from the request stats), OR semantics. `provider=nvidia_nim,novita` exports exactly those two providers. Web Search scope keeps the provider filter and hides the model filter (no models there).
- **"All time" period** — sends no `since`, exports the full lifetime table.
