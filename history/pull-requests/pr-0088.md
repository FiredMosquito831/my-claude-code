## What changed

When a launcher was running, the Windows installer deferred the update and printed only a short "staged" notice — losing the command reference that a Linux/WSL install shows. The full mcc message (start the proxy, use a coding agent, manage/inspect, legacy aliases, restart note) now prints on both paths.

Extracted `Write-MccCommandReference` and call it from:
- the direct-install success message, and
- the deferred (app running) path inside `Start-DeferredInstall`.

So Windows and WSL/Linux show the same content after install. The staging notice still leads before the reference in the deferred case.
