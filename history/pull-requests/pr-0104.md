## Description

## What

Adds a fourth dashboard theme, **Velvet**: a deep navy base (`#0a1220`) with a vibrant velvet-red accent (`#e6435e`) tuned for a "silk / velvet" read — surfaces step up like a velvet pile, and shadows carry a faint crimson bloom instead of flat black.

## Why

The user asked for "a theme that is a mix of navy blue with velvet red but vibrant and deep like silk and or velvetty with nice contrasts."

## Design decisions

- **Semantic tokens only** — the theme swaps the same `--*` tokens the other themes swap, so every surface picks it up with zero bespoke selectors (flat+dense preserved).
- **Red is the brand hue, not the failure hue** — success/warning/error stay green/amber/red so crimson is unmistakably the accent and never collides with "something is failing."
- **Contrast is measured, not guessed**: body text 15.6:1 on navy, accent-on-navy 4.76:1 (clears AA), status colors 6.75–9.97:1.
- **`applyTheme()` whitelist updated** — without this, `velvet` silently falls back to midnight.
- **Built with `/ui-ux-pro-max:ui-ux-pro-max`** — the skill's dark-navy OLED foundation informed the base; no exact "velvet" palette exists in its database (said so explicitly), so the crimson was chosen to maximize vibrancy while clearing 4.5:1.

## Verification

- 79 admin tests pass, including two new guards: **token parity with the paper theme** (a missing token → a surface silently falls back to midnight) and **WCAG contrast** of text + accent on navy. The token-parity guard was mutation-proven to fail when the velvet block is removed.
- jsdom: 4 switcher options, `applyTheme("velvet")` sets the dataset attr, all 83 emitted classes still styled, canvas charts feed the velvet accent via the existing `token()`/`chartRedrawers` path.

## Residual risks

- Canvas pixel rendering is not verified (jsdom stubs the canvas); real bars/gridlines render from the same CSS tokens, but a browser smoke test is the only way to be sure.
- The brand-mark gradient's white-on-accent end is ~3.9:1 (matches the existing midnight theme's behavior for its emerald); fine for large text.
