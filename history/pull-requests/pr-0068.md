## Description

Compaction set `PRAGMA page_size` before its `VACUUM`. **SQLite refuses to change page size on a WAL database**, so the pragma was silently ignored — the code, the v4.47.0 release notes and the docs all said 16 KB, and the real database came out at 4,096.

Caught by printing `page_size` after compacting the live log rather than trusting the code that set it:

```
db size    : 0.29 GB
page_size  : 4,096     <- claimed 16,384
```

Honouring the claim would mean dropping out of WAL around the vacuum and back afterwards. That is a real risk to take on someone's only copy of their history for an uncertain few percent, so **the claim goes instead** — code, README and USAGE.

Everything compaction actually does is unchanged and already verified on the live database: **1.73 GB → 0.29 GB**, all **50,034 bodies compared against a pre-compaction backup, zero mismatches**.
