## Description

Adds three hosted gateways as built-in providers. Each was verified against its **live API** rather than configured from documentation, which changed two of the three implementations.

## What the probing changed

Nous Portal and Kilo do not serve a plain OpenAI-compatible model list — both return **OpenRouter's exact dialect**:

```
$ curl -s https://inference-api.nousresearch.com/v1/models   # 200, 354 models
$ curl -s https://api.kilo.ai/api/gateway/models             # 200, 349 models
NOUS: reasoning params {'include_reasoning': 224, 'reasoning': 224, 'reasoning_effort': 110}
KILO: reasoning params {'reasoning': 224, 'include_reasoning': 224, 'reasoning_effort': 90}
NOUS: 311 tool-capable of 354      KILO: 283 tool-capable of 349
```

Entries carry `supported_parameters`, `canonical_slug`/`top_provider` and `pricing`. Treating them as generic OpenAI endpoints would have advertised all 354/349 models including those that cannot run tools, and dropped the reasoning metadata the model picker uses.

So the dialect moves to a neutral owner, `providers/openrouter_gateway.py`, holding the tool-capability filter, the `reasoning` object encoder and the `reasoning_details` replay. OpenRouter, Nous Portal and Kilo are now thin subclasses — this keeps the "no provider imports another provider's utils" rule without three copies of ~130 lines.

**Cline is deliberately not on that path.** Every route on `api.cline.bot` returns 401 without a key, including `/models`, so its catalog shape could not be verified:

```
https://api.cline.bot/api/v1/models  -> 401 {"error":"Unauthorized: ..."}
```

It gets a plain OpenAI-compatible profile with generic model listing and **no reasoning parameters** — sending an unverified `reasoning` object risks a 400 on every request. If the catalog is later confirmed OpenRouter-shaped, switching it is a one-line change.

## A docs-driven choice that would have been wrong

The Hermes models are Nous's headline models, but the live catalog shows they advertise `reasoning` **without** `tools`:

```
nousresearch/hermes-4-70b    tools=False  reasoning=True
nousresearch/hermes-4-405b   tools=False  reasoning=True
```

They are filtered out of the picker by design, so the smoke default uses a verified tool-capable model instead. A test pins this so the filter cannot silently regress.

## Residual risks

- **Cline's reasoning support is unknown, not absent.** If it does accept a `reasoning` object, thinking is currently unavailable through it. This is the conservative direction — a wrong guess would 400 every request instead.
- **`reasoning_details` replay is applied to Nous and Kilo unverified.** It is a no-op unless the client sends `redacted_thinking` blocks, so the blast radius is limited to encrypted-reasoning replay on those two gateways.
- Neither gateway's native `pricing`/`context_length` is read into `ProviderModelInfo` though both report it. Deliberately out of scope.
