## Corrections — checked against the code, not assumed

**1. The auth token is not "any value".** I wrote that any non-empty token works. It isn't true: `ANTHROPIC_AUTH_TOKEN` ships as `freecc` in `.env.example` and is compared in constant time against the bearer token the agent sends (`dependencies.py:71-78`). A mismatch is a 401. It only *looks* optional because the code default is empty — which disables auth entirely.

**2. Claude Code is configured via `settings.json`, not shell exports.** I recommended `export ANTHROPIC_BASE_URL=...`. The settings file **wins over exported variables**, so that advice would silently do nothing for anyone who already had `~/.claude/settings.json`.

**3. The proxy does not bind to loopback.** `host` defaults to `0.0.0.0`, so it is reachable across the network; only the Admin UI is loopback-restricted. The old text said the opposite — the wrong direction to be wrong about a security property.
