## Description

Closes the three gaps found in the earlier rotation audit. 4.16.0 -> 4.17.0 (MINOR).

## 1. The limiter and the rotation engine did not know about each other

Verified before the fix:

```
limiter.is_blocked()      -> True     (60s reactive block)
rotation state of key 0   -> HEALTHY
rotation still selects    -> 0
```

So with 3 keys and key 0 throttled, round-robin still sent a third of traffic to it, and those requests **waited inside `wait_if_blocked()`** while idle keys went unused. `acquire()` now takes an `avoid` set.

**Fallback matters:** if every credential is unavailable, selection proceeds normally rather than returning -1. Refusing outright would turn a soft guardrail into a self-inflicted outage.

## 2. Backoff ignored what the provider actually said

Every 429 waited a hardcoded 60s. Now parsed from the upstream headers:

```
retry-after: 5            -> 5.0
retry-after-ms: 2500      -> 2.5
x-ratelimit-reset: 6m0s   -> 360.0
x-ratelimit-reset: 250ms  -> 0.25
no/garbage headers        -> 60.0   (unchanged fallback)
retry-after: 999999       -> 3600.0 (capped)
```

`retry-after-ms` is read first since it is the most precise.

## 3. Daily quotas had no representation

A daily cap resets at a **fixed wall-clock instant**, not N seconds after a failure — structurally inexpressible as a cooldown. `DailyQuotaTracker` counts per credential per *provider-local* day, with `{ENV}_DAILY_LIMIT` and `{ENV}_QUOTA_RESET_UTC_OFFSET` (Gemini = -8).

In-memory by design: the tracker avoids wasting requests rather than enforcing billing, and persisting would add a write to every request path. Documented in both the README and `.env.example`.

## Also

An unrecognised `{ENV}_ROTATION` value now warns instead of silently pinning traffic to key 0 — previously a typo like `round-robin` disabled rotation with zero signal.

## Design note

`throttle_remaining()` is a `BaseProvider` method returning 0.0, overridden by the two providers that actually hold a limiter. I first tried an optional `_rate_limiter` on the base, which weakened the type at 7 existing call sites; overriding keeps those sites non-optional.
