## Deliberately self-contained

No images, no fetches, no settings sections. The page stays readable when a provider is unreachable or the machine is offline — which is precisely when someone is most likely to open it.

## One real bug this surfaced

The view registry assumed every group owns a settings container:

```js
VIEW_GROUPS.forEach((view) => {
  byId(view.containerId).innerHTML = "";   // null for a static view
});
```

A static view has no container, so this would throw and **take the entire settings render down with it**. Both call sites now skip a missing container.
