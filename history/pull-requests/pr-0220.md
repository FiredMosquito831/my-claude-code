## Description

# Observability that tells the truth: the knobs, the credential, and the measurement

The dashboard could not be trusted about the one thing it exists to report — what actually left this process. This fixes the writer, the reader, and the three places a NULL meant something different.

## What was wrong

Measured on a 204 MB copy of the live request log (10,242 requests / 74,126 attempts):

| | |
|---|---|
| attempts in one day with a stored wire body | 455 |
| of those, truncated | **212** |
| truncated previews still containing `reasoning_effort` | **0 / 212** |
| truncated previews still containing `temperature` / `top_p` | **0 / 212** |
| attempts with `reasoning_emitted = 0` under a non-suppressed adaptation | 148 |
| requests with a NULL `key_label` | 399 / 10,242 (62 of them with `key_index = 0`) |
| succeeded minimax attempts asked for reasoning | **3 of 6,614** — and it thought **0** times |
| succeeded hy3 attempts asked for reasoning | **0 of 977** — and it thought **977** times |

1. **The stored body was cut mid-string, and the cut landed on the knobs.** `summarize_wire_body` serialised with `sort_keys=True` and truncated at 8,000 characters, so a Claude Code request with ~59 tools spent the entire budget inside `tools` and every alphabetically later key fell off. What was stored was a cut JSON string under `_preview`, printed verbatim into a `<pre>`, unparseable by anything. The knobs were never actually lost — `params.wire` is not truncated and had them on 455/455 — the UI read three fields off it and discarded the rest.
2. **Gating and the wire contradicted each other in silence.** An adaptation reading *"enabling thinking and discarding effort 'max'"* sat beside a wire pane whose attempt had carried effort max, with nothing drawing the relation. The badge said "no reasoning sent", which reads as a fault — after #219 it is the correct outcome for a toggle-only model on an effort-only host.
3. **A request whose provider has no instrumented commit boundary showed no wire pane at all**, which reads as "no request body was sent".
4. **Attempts had no credential.** `requests.key_index`/`key_label` hold the last credential of the whole request, and the fully-benched path raised before recording one at all — so every benched-out request rendered as an ordinary keyless one.

## What to expect now

- **Every knob is stored, whole.** Non-content keys are emitted first and complete; only `messages`/`tools` degrade, to counts and names. The stored body always parses as JSON. The cap is now a setting: `REQUEST_LOG_WIRE_BODY_MAX_CHARS` (default 8000), and it bounds message/tool structure only.
- **A knobs block in the wire pane**, read from `params.wire`, so the knobs are legible even on a body stored by the old writer (`c-after-wire-knobs.png` — `reasoning_effort = max` beside a `<pre>` that never reaches the key).
- **Three honest states**: `reasoning sent: <value>`, `no reasoning instruction sent (model default applies)`, `reasoning not measured`. The pane is never hidden while a request has attempts (`c-after-not-measured.png`).
- **A contradiction badge** when the body carried nothing and gating had decided otherwise — keyed on a new `requests.reasoning_adaptation_kind` column carrying `ReasoningAdaptation.kind`, never on the message text (`c-after-contradiction.png`).
- **Per-attempt credentials** on `request_attempts`, rendered in the chain, with `(-1, "(no key available)")` for a fully benched pool.
- **A measured chip on the Models page**: "last 7d: reasoning requested X/N, returned Y/N" — two independent facts (`c-after-models-measured.png`).
- **One NULL convention**: a dash means not measured, a zero means measured and zero. `"keyless"` is gone; it invented a fact.

## Action required

None. Old rows keep their stored shape and render with their note; attempts written before the new columns show **"not measured"** and a dash, which is exactly what they are. Nothing is backfilled — rewriting stored bodies would fabricate data that was never captured.

## Known and deliberate

- **Attempt-level credential health is not shipped.** Measured at **109 ms** without `rotated_away` and **162 ms** with it on the 204 MB copy — affordable, but in this change it would land as a payload field with no rendered surface, and an unwired feature is worse than a missing one. Credential health stays request-level; the per-attempt truth is in the chain.
- **Request-level `reasoning_adaptation` still names one model while a fallback answered.** Moving it onto `request_attempts` is a schema and a gating-signature change.
- **Vertex has no commit boundary**, so its attempts are permanently "not measured". This makes that visible instead of hiding the pane.
- **Body redaction is by key name and credential shape**; a secret in an innocuous field with an unremarkable shape still survives.

## Residual risks

1. **Stored bodies can get larger.** Knobs are emitted whole even when they alone exceed the cap, so a pathological `extra_body` stores more than the setting's number suggests. Deliberate: a cut knob is unrecoverable, a cut turn list is not. The setting's description says what it bounds.
2. **Two body shapes coexist forever.** Rows written before this render as the legacy cut string with a note. No backfill.
3. **The measured chip is a rolling window** bounded by `REQUEST_LOG_MAX_ROWS`. A model whose traffic aged out shows no chip, which can look like "never measured" for a model that was heavily used. The chip names its window.
4. **`reasoning_by_model` joins two tables on every Models-page load.** Cached 5 s, indexed, off the event loop, and measured above — but unmeasured on a database far larger than 204 MB.
5. **Per-attempt attribution is only as good as the slot.** A provider that internally retries across keys inside one attempt still attributes that attempt to its last key. A smaller lie than the per-request one, not the absence of one.
6. **The contradiction badge depends on a column, not on prose** — which is the point — but it therefore fires on nothing at all for every row written before this release, and for any adaptation whose kind is `unchanged` or `suppressed`.
