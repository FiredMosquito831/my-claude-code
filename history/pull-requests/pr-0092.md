## What

Both `mcc-claude` and `fcc-claude` (they resolve to the same entry point, `cli.launchers.claude:launch`) now set `ENABLE_WEB_SERVER_TOOLS=true` on the launched Claude Code session.

Web server tools need the proxy-side execution path, so sessions launched through the proxy should always have them available. The variable is forced in `build_minimal_claude_proxy_env` — the env policy used **only** by this launcher — so the `-old` / legacy launcher (`launch_legacy`, full-env builder) is untouched.
