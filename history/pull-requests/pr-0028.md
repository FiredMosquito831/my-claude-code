## 1. Unreported caching now reads as "—", not "0.0%"

A provider that never reports prompt caching rendered as **0.0%**, which looks like *caching is broken here* rather than *this upstream doesn't tell us*.

The stats now count how many requests actually carried a cache figure. The rate shows **—** when that count is zero; a provider that genuinely reports no hits still shows **0.0%**. Measured-zero stays distinguishable from unsupported.

```
reported zero     -> 0.0%
never reported    -> —
real NIM sample   -> 2.6%
```

This matters concretely for the NIM question: NVIDIA's hosted endpoint returns a constant token or two under `prompt_tokens_details` rather than doing real prefix caching. Verified by sending the same 9,039-token prompt four times:

```
call 1: prompt=9039  cached=16
call 2: prompt=9039  cached=16
call 3: prompt=9039  cached=16
call 4: prompt=9039  cached=16
```

Real prefix caching would show ~9,000 on the repeats. NVIDIA documents prefix caching as a **self-hosted** toggle (`NIM_ENABLE_KV_CACHE_REUSE=1`), not something enabled on the shared hosted endpoint — so a near-zero rate there is accurate, and our mapping is correct.
