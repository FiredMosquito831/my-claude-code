## The awkward facts are stated, not smoothed over

Each of these is a question somebody will otherwise ask:

> app-mode is the default because three things the dashboard depends on break inside an embedded webview: `window.open` (both OAuth logins), `<a download>` (the analytics export), and `navigator.clipboard` (every copy button).

- **pywebview ships disabled**, with the reason given rather than hidden.
- **`DESKTOP_*` settings apply on the NEXT launch**, not to a running tray — a setting that appears to do nothing is worse than one that is absent.
- **WSL and headless have no tray**; `mcc-server` is the path, reached from a browser on the Windows side.
- **`--desktop` is opt-in**; a default install creates no shortcuts.
