**A repin can no longer drift.** That release's checksum file is vendored at
`tests/fixtures/desktop_shell/v6.45.2/`, and `test_desktop_shell_pin.py` compares
the in-source table against it on every run. The network-gated test already made

fixture directory is named for the pinned tag, so a repin that forgets to vendor
fails on a missing directory rather than passing against the previous release's
digests. `.gitattributes` checks the directory out with `-text` so the
comparison is against bytes and not against a re-encoded copy of itself.

## 2. The winget manifest

`desktop-shell/installer/winget/` — three files at **manifest schema 1.28.0**
(the newest published in `microsoft/winget-pkgs` `doc/manifest/schema/`; not
guessed) for `FiredMosquito831.MyClaudeCode` 6.45.2:

- `Architecture: x64`, `InstallerType: inno`, `Scope: user`, the v6.45.2
  `MyClaudeCode-Setup-windows-x86_64.exe` URL and its published SHA-256;
- `AppsAndFeaturesEntries` with `ProductCode: '{5FC8D5C3-…}_is1'` — the `.iss`
  `AppId` with `_is1`, read out of the `.iss` rather than repeated — plus the
  `DisplayName`, `DisplayVersion` and `Publisher` Inno actually writes;
- **no `InstallerSwitches`**: `inno` already means winget supplies
  `/SP- /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`
  (`winget-cli`'s `GetDefaultKnownSwitches`), and its docs ask you not to
  duplicate it;
- **no `Commands`**: the installer deliberately puts nothing on `PATH`.

**Publisher segment = the GitHub owner.** The community repository asks for "the
name of the company that publishes the tool"; there is no company, and its own
convention for that case is the account name (`sharkdp.bat`,
`ajeetdsouza.zoxide`). It is also the only half of the identifier a user could
guess from the URL they downloaded from. This deliberately differs from
`AppsAndFeaturesEntries.Publisher` (`My Claude Code`), which is not a display
name but the string winget reads back out of the registry.

**Rendered, not written.** `render.py` (stdlib only) reads the six values that
live elsewhere and would go stale silently — the `AppId`, the three Apps &
Features strings, `pyproject.toml`'s licence, and the digest from the release's
checksum file — and prints the manifests. `tests/scripts/test_winget_manifest.py`
asserts that rendering v6.45.2 reproduces the committed files byte for byte, so
the checked-in copies are safe to read and to copy into a submission, and a
changed `AppId` is a red test rather than a package winget quietly stops
recognising.

```
uv run --offline python desktop-shell/installer/winget/render.py v6.45.2
```
