## Description

A checkbox has two positions. A settings file has **three** states: the key says `true`, the key says `false`, or the key is **absent** and Claude Code applies its own default.

Unchecking a box wrote `false` — a different instruction from *"I have no opinion"*. For a setting whose default is `true`, that actively changes behaviour you only meant to stop overriding. And there was no way to say "not set" at all, so once a boolean was written it could never be taken back out from this page.

## Now

```
settings key    [ True ] [ False ] [ Not set ]
env variable    [  On  ] [  Off  ] [ Not set ]     writes "1" / "0" / removes
```

Every state visible at once, one click to reach any of them. **"Not set"** carries a tooltip naming the default it hands back to, so it's an informed choice rather than a guess.

**The presence-read family is the exception, with a reason.** Claude Code reads only *whether* `DISABLE_TELEMETRY` and its five siblings exist, so `false` isn't a state they can be in — those get `On | Not set`, and the row's `presence` badge already explains why. `FORCE_HYPERLINK` keeps all three, since it's parsed as a number and `0` genuinely is off.

## A deliberate break with convention

The selected segment is a raised neutral surface with an **accent underline**, not accent-coloured text. Accent text is what the rest of this dashboard uses for a selected state, but at 12px on the light theme's raised surface it measures **3.4:1** — under the 4.5:1 floor. `--text-strong` on `--panel-strong` measures **16.9–19.8:1** across all four themes, and the underline carries the same meaning at any contrast.

The marker is a border rather than an inset shadow because **High Contrast sets `--shadow-sm` to `none`**, and `box-shadow: none, inset ...` is an invalid list — the whole declaration was dropped and that theme lost both the marker *and* the raised surface. Caught by measuring all four themes.

The segments are a real `radiogroup` labelled by the row's setting name, so it's keyboard-navigable and announced.
