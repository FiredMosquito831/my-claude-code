## Description

## What was missing

Anthropic's adaptive extended thinking **already worked** — `providers/anthropic_messages/request.py` defaults to `thinking {"type":"adaptive"}` when nothing else is specified. But there was no way to **ask** for it. A tier could be Off, From client, or a fixed effort, and nothing else.

This adds **Adaptive** alongside them, so a tier can hand the decision back to the model per request instead of pinning one effort for every call.

## How it's represented

A new `ReasoningControl.ADAPTIVE` member rather than overloading an existing one, because it is a genuinely third intent:

| control | meaning |
| --- | --- |
| `DEFAULT` | no opinion was expressed |
| `ON` | reasoning demanded, optionally at a named effort |
| `ADAPTIVE` | the model should choose, per request |

Collapsing it into either would lose the distinction the request log records and the Anthropic encoder acts on.

`requests_reasoning` deliberately answers **False** for it: adaptive names no effort and no budget, so a generic encoder has nothing representable to send and falls through to the provider's own default — exactly today's behaviour. Only an encoder with its own adaptive channel acts on it, and only Anthropic Messages has one. **No provider gains a new wire field.**

## Honest scope

models.dev publishes **no adaptive signal** — its only `reasoning_options` types are `effort`, `toggle`, `budget_tokens`. So this cannot be capability-driven and does not pretend to be; it is an Anthropic-family control exposed as a choice.

Per-model gating still applies *around* it: a model known not to reason has reasoning suppressed even under an adaptive tier, and an unknown model is returned unchanged by identity.

**Nothing changes for anyone who does not select it.** Anthropic's existing default-to-adaptive is untouched, and every other preference resolves exactly as before.

## Residual risks

**Inert unless a tier routes to Anthropic.** On a config pointing at other providers, selecting Adaptive resolves to "let the provider decide" — the same wire result as today. That is deliberate and stated in the docs rather than hidden, but it means the option can look like it does nothing depending on where a tier points.

**No live Anthropic call.** Verified against the emitted body and the resolved policy, not a real API response — consistent with the rest of this arc.
