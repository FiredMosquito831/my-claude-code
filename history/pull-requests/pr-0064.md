## Description

Follow-up to #63, from benchmarking the read paths. Compression turned out to be a mixed result, and search was the bad half.

## Measured on 4,000 real requests

| operation | inline | compressed | |
| --- | --- | --- | --- |
| `stats()` aggregate | 311 ms | **53 ms** | 5.8x faster |
| list page of 50 | 18 ms | 41 ms | 2.2x slower |
| detail read x50 | 150 ms | 198 ms | 1.3x slower |
| search, selective | 1,443 ms | **9,056 ms** | 6.3x slower |

The aggregate got much faster because it no longer walks overflow pages — that is the dashboard's main query, so it is the one that mattered most. Search got much slower because the predicate decompressed *and* JSON-parsed every row.

## The fix

Most rows do not match, and for those the JSON parse and UTF-8 decode are pure waste. JSON encoding only rewrites `"`, `\` and control characters, so a needle containing none of them appears in the stored blob byte for byte — meaning **absent from the encoded bytes proves absent from the decoded text**.

That makes a bytes-level test a sound *rejection* filter. It is deliberately not used as an acceptance test, because it can match a key name or structural punctuation, so a hit is still verified against decoded text. A needle that JSON would escape skips the filter entirely.

| search term | inline | compressed | | matches |
| --- | --- | --- | --- | --- |
| selective miss | 1,443 ms | **1,919 ms** | 1.3x slower | 0 |
| rare word | 1,578 ms | 1,906 ms | 1.2x slower | 1 |
| common word (`the`) | 383 ms | 5,493 ms | 14.3x slower | 3,991 |

Selective search went from 6.3x slower to 1.3x. A term matching 99.8% of rows is unchanged and inherently so — when nearly everything matches, the decode is the work rather than the waste.

## Correctness

Three tests pin what could go quietly wrong:

- needles containing quotes, backslashes and newlines still match (they skip the filter)
- structural fragments like `","`, `{"i":`, `"o"` match nothing
- an inline store and a compressed store return **the same row ids** for the same searches
