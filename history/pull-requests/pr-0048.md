## Description

## Two small, defended changes rather than a rewrite

Both views were **already designed** — the Guide's sticky scrollspy TOC has been there since 4.23.0 (PR #29) and the Get Started cards since 4.29.0. The useful work was auditing them against a design plan, not replacing work that holds up.

**Get Started.** The "N of M essential steps done" line was plain muted text carrying the only number on the page. It is now a label plus a filled track, width driven by the same ratio, with `role="progressbar"` and matching aria values. A bar shares the step list's own vertical axis, so it reads as the list being filled in rather than a widget parked above it.

A donut with a percentage in the middle was considered and **rejected** — for that same axis reason, and because a big number in a ring is the stock answer.

**Guide.** An "On this page" eyebrow above the TOC rail, reusing the existing global `.eyebrow` class rather than inventing type, so the rail reads as deliberate wayfinding instead of a bare list of links.

Tabs-instead-of-scroll was considered and rejected: tabs hide how much is left, break find-on-page, and kill deep links like `#guide-cli` — all of which matter more for "reference read while stuck" than novelty would gain.

## Cut during self-critique

The progress bar briefly had an `is-complete` state that swapped the fill to a gradient on finishing. It used only existing tokens, but it added a visual event carrying nothing the bar's fullness did not already say. Removed from **both** the CSS and the JS branch that set it, rather than left as dead weight — verified gone from source, not merely unreferenced.

## Found while auditing, not designed

- `.guide-toc a:focus-visible` changed only its background, so **keyboard focus was invisible on every TOC link**, while every other control in the app gets a 2px accent outline.
- The highlight-pulse animation and the progress transition had no `prefers-reduced-motion` coverage.

## Palette and type are inherited, deliberately

These are two views inside a shipped dashboard. A new face or hue for two of them would break the one thing holding the product together. That is the decision, not an omission.
