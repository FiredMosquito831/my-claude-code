## What

Adds `JOURNAL.md` to `.gitignore`, next to the existing `WORKING-NOTES.md` entry.

## Why

`WORKING-NOTES.md` (the local operator notes) had grown to 6,250 lines, roughly
a fifth of which was a duplicated changelog. It has been split in two:

- `WORKING-NOTES.md` — the durable half: practices, preferences, methods, lessons, open debt.
- `JOURNAL.md` — the dated half: per-release arcs, the old version tables, point-in-time machine state.

Only the first was ignored, so the new file sat untracked and visible. A
`git add -A` from a fresh worktree would have staged ~126 KB of local notes.

Both files are operator notes, not repository content — the version history they
record already lives in `git tag` and GitHub releases, which are authoritative
where the journal disagrees.
