## Description

## What was wrong

Native-Anthropic routes emitted thinking budgets from an invented flat map (`512..8192` by effort name) whenever any effort was set — regardless of what the model accepts. Modern Claude models expose a native effort channel instead; sending them a synthetic budget is a guaranteed-400 risk, and Part IV §1 bans invented limits besides.

## The fix

The encoder now consults the same `ModelReasoningCapability` lookup the gating layer uses: models reporting **effort** control get the native effort channel; models reporting **budget** control keep enabled+budget_tokens clamped to their real limit with the documented 1024 floor; **unknown models stay byte-identical** to today (§163 identity property, asserted by test). The invented map is retired exactly where a confirmed channel exists.

Scope note: landed at both body-building call sites so the fix is live in production, not just in the request builder.
