## Description

## The Guide was named after the software

Sections were called Models, Analytics, Key rotation, Security. Someone opening a guide is **stuck on a task**, not curious about a feature area. The headings now say what you are trying to do:

| Was | Now |
| --- | --- |
| Models | Map model tiers |
| Claude Code (CLI) | Point Claude Code here |
| Analytics | See what a request actually did |
| Key rotation | Use more than one key safely |
| Web search | Search the web |
| Security | Lock it down |

Content changing shape to match how it is read, rather than a visual layer on top of it.

**Every `id="guide-..."` is byte-identical.** Deep links, the scrollspy and the Guide's own cross-references key off those — renaming a heading is a copy edit; renaming its id breaks every link anyone saved.

## Three cross-links, a copy button

Three links, each making a connection the prose already states clickable. This needed a `.guide-body a` rule, because there was none — prose links would otherwise have rendered in **default browser blue**, precisely the kind of unplanned hue a fixed palette exists to prevent.

Code blocks get a copy button. They hold env vars, a `settings.json` snippet and shell commands a reader is going to paste. `navigator.clipboard` is **feature-detected rather than assumed**, so a browser that withholds it never renders the button instead of rendering a broken one, and the write promise fails silently — the text stays selectable either way.

## Get Started splits by necessity

Three required steps form a genuine causal chain: a provider, then a model, then pointing the client at it. The four optional ones are independent extras. Rendering all seven as one list with a per-card pill as the only difference meant **reading every pill to learn which three actually matter**.

The split is derived from `step.optional` while walking the already-ordered array — no reorder, no new field, nothing persisted, and the expand/advance state machine is untouched. It also makes the progress bar honest: "N of M essential steps done" now describes the group directly above it.

A step that is **done and collapsed** shows a check instead of a chevron, so scanning the closed list distinguishes "closed because handled" from "closed because I have not opened it yet" without reading text. Deliberately nothing more — no numerals, no ring, no celebration. This is someone configuring a proxy.

## One trade-off, stated rather than hidden

The rail is a 224px column; after padding, ~180px, or roughly 25 characters at 13px. "Point Claude Desktop here" is 26. Rather than gamble on wrap behaviour that cannot be rendered and checked here, the three "Point X here" entries were shortened to plain app names **in the TOC** while keeping the fuller task phrasing on the heading, where width is not a constraint.

That is a real retreat from task-framing for those three, bought with certainty.

## Rejected, recorded so they are not re-proposed

- **In-page search** — duplicates Ctrl+F, and a single scrolling column was chosen precisely to keep find-on-page and `#anchor` links working.
- **A density pass** — a stressed reader wants topics separated, not crammed.
- **Step numerals** — order is already carried by the grouping and position.
