## Description

Found by looking at the file the first successful four-platform release actually produced ([run 33871599947](https://github.com/FiredMosquito831/my-claude-code/actions/runs/33871599947)), rather than at the file #273 said it would produce.

`SHA256SUMS-desktop-shell.txt` on `v6.43.0` came out with three lines in one format and one in another:

```
57883dc18219d223e80e04ad9cbae306e04e18d907678c788b265c560694f0f8  MyClaudeCode-linux-x86_64.tar.gz
088360a67dcd32ab00ed1eedb2427645980926b74afe0253738ceafea601768a  MyClaudeCode-macos-aarch64.tar.gz
648460de2d3df68292a7e83401d12345b24b734073fd1405b99aa3ccba953238  MyClaudeCode-macos-x86_64.tar.gz
b4d8255397bc8000278665c92fd6196035cc5c030554784c1b6eb37094eea478 *MyClaudeCode-windows-x86_64.zip
```

Note the `*` on the last line. Git for Windows' `sha256sum` defaults to **binary** mode and writes `<digest> *<name>`; GNU coreutils on Linux writes `<digest>  <name>`.

Both are valid input to `sha256sum -c` — which is exactly why the workflow's own verification step passed and why nothing caught it — but they are not the same bytes. #273 documented the file as "exactly `sha256␣␣filename` lines … so the Python side can parse it", and S4 is going to parse it into the `(platform, arch) → sha256` table. A format that depends on which runner produced which line is not a contract.

## What changes

- Each leg builds its line with `printf '%s  %s\n' "$digest" "$asset"` from the digest alone, instead of writing whatever its `sha256sum` felt like emitting.
- The aggregating job asserts, before uploading, that **every** line matches `^[0-9a-f]{64}  MyClaudeCode-[a-z0-9_.-]+$`. A stray mode marker now fails the release rather than surfacing in Python months later. (Regex checked both ways against a fixture containing one good line and one `*` line.)
- `desktop-shell/README.md` now shows four real lines from that release rather than an elided sketch, and says why the line is rebuilt.

No Python change, so no version bump and no release. The checksum file on `v6.43.0` is replaced by re-dispatching after this merges; `--clobber` makes that safe.
